# Python do Zero

Curso de Python para iniciantes em 10 blocos. Cada bloco terá aula, exemplo executável, exercícios TXT, consulta TXT e testes.

Comece por [COMECE_AQUI.md](COMECE_AQUI.md).

Executar: `python bloco01/bloco01_exemplo.py`
Testar: `python -m pytest -q`

TXT é material de leitura, não código Python.
