# Bloco 3 — Operadores e textos

Operadores: +, -, *, /, // (divisão inteira), % (resto), ** (potência). Comparações: ==, !=, >, <, >=, <=. Não confunda = (atribuição) com == (comparação).

Textos podem ser limpos com strip(), normalizados com lower() e medidos com len(). Dividir por zero gera ZeroDivisionError. Valide o divisor. Execute o exemplo e rode python -m pytest bloco03 -q.
