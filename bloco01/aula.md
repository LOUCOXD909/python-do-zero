# Bloco 1 — Primeiros passos

Python executa instruções de cima para baixo. `print()` mostra dados no terminal. Textos ficam entre aspas. Comentários começam com `#` e são ignorados.

Uma função é definida com `def`. `return` devolve um valor; `print` apenas o mostra. Python diferencia maiúsculas de minúsculas: `Print` não é `print`.

Execute `python bloco01/bloco01_exemplo.py`, altere o nome, leia consulta.txt e resolva exercicios.txt. Depois rode `python -m pytest bloco01 -q`.
