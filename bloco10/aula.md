# Bloco 10 — Projeto final independente

Agora crie um projeto NOVO em uma pasta separada, no VS Code ou na IDE que preferir. Não entregue o exemplo do curso como se fosse um projeto próprio.

Escolha uma ideia: lista de tarefas, controle de gastos, quiz de perguntas ou inventário de jogo.

## Requisitos mínimos
- Pelo menos cinco funções com responsabilidades claras.
- Condicionais, loops e listas ou dicionários.
- Validação de entradas e mensagens de erro úteis.
- Pelo menos oito testes automatizados.
- README com instalação, execução, exemplos e testes.
- Nenhuma senha, token ou dado pessoal no repositório.

## Processo
1. Descreva o problema e liste requisitos.
2. Planeje as funções.
3. Implemente uma funcionalidade por vez.
4. Teste casos comuns, limites e entradas inválidas.
5. Execute python -m pytest -q.
6. Documente como executar do zero.

Envie à IA o enunciado, arquivos, README e saída real dos testes. Use RUBRICA.md para pedir nota de 0 a 100, erros concretos, explicações, testes faltantes e três próximos assuntos. A IA não deve fingir que executou código que apenas leu.
