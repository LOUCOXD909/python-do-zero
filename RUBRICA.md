# Rubrica do projeto final

| Critério | Pontos |
|---|---:|
| Requisitos e funcionalidades | 30 |
| Lógica e casos extremos | 20 |
| Organização e legibilidade | 15 |
| Funções e responsabilidades | 10 |
| Validação e erros | 10 |
| Testes automatizados | 10 |
| README e instruções | 5 |
| Total | 100 |

A IA deve dar nota por critério, listar requisitos atendidos e faltantes, apontar erros concretos, explicar correções, sugerir testes faltantes e recomendar três próximos assuntos. Não deve inventar arquivos nem afirmar que executou código se não executou.

Prompt: Avalie meu projeto de Python para iniciante usando esta rubrica. Dê nota de 0 a 100 justificada por critério. Liste erros com arquivo e linha quando verificável. Explique como corrigir sem reescrever tudo. Sugira casos de teste faltantes e três assuntos seguintes. Declare o que não pôde verificar.
