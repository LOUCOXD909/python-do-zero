# Bloco 7 — Funções

Defina funções com def, receba dados por parâmetros e devolva resultados com return. print mostra uma informação; return entrega um valor para quem chamou a função. Parâmetros podem ter valores padrão. Variáveis criadas dentro da função são locais.

Prefira funções pequenas com uma responsabilidade clara. Valide dados e lance ValueError quando não respeitarem as regras. Rode python -m pytest bloco07 -q.
