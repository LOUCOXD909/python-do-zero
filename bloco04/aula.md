# Bloco 4 — Condicionais

Use if, elif e else para escolher caminhos. Os dois-pontos iniciam um bloco e a indentação, normalmente quatro espaços, define quais linhas pertencem a ele. Condições produzem True ou False.

and exige ambas verdadeiras; or exige ao menos uma; not inverte o resultado. A ordem importa: coloque condições específicas antes das gerais. Teste abaixo, no limite e acima dele. Rode python -m pytest bloco04 -q.
