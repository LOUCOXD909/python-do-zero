# Bloco 6 — Listas e dicionários

Listas guardam itens em ordem; índices começam em zero. append adiciona, len conta e um índice inexistente gera IndexError. Dicionários guardam pares chave-valor, como {"nome": "Bia"}. Acesso por chave ausente pode gerar KeyError; get permite um padrão.

Use listas para coleções ordenadas e dicionários para dados identificados por nomes de campos. Rode python -m pytest bloco06 -q.
