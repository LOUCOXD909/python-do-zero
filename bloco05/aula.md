# Bloco 5 — Repetições

Use for para percorrer uma sequência ou repetir uma quantidade conhecida. range(5) produz 0, 1, 2, 3, 4: o limite final não entra. Use while quando a repetição depende de uma condição. Atualize algo no loop para evitar repetição infinita.

break encerra o loop; continue pula para a próxima repetição. Um acumulador guarda resultados parciais, como uma soma iniciada em zero. Rode python -m pytest bloco05 -q.
